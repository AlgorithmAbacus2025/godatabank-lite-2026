# GoDataBank project definition

Status: consolidated orientation, not a replacement constitution.

GoDataBank is a searchable repository of machine-curated evidence from official institutions. Mission: collect, verify, organise, summarise, publish. Its identity and admissible evidence are defined by the [constitution](CONSTITUTION_V0_1.md) and [source admission rule](SOURCE_ADMISSION_RULE.md).

The existing Lite implementation includes a World Bank metadata pipeline, topic research workbench, and static HTML reports. The tracked code is a prototype; the presence of a design document does not prove implementation or production readiness. The Lite scope excludes dashboards, databases, user accounts, subscriptions, automatic publishing, frontend frameworks and ALIS Studio under the [Lite operating principles](ALIS_LITE_OPERATING_PRINCIPLES.md).

The existing public site and evidence records are to remain intact during documentation cleanup. Reusable ALIS Core functionality is conceptually separate from GoDataBank's product layer, as described in the [repository architecture plan](reviews/ALIS_CORE_REPOSITORY_ARCHITECTURE_PLAN_V1_0.md). Any wider agent integration requires an explicit architecture and implementation decision.
