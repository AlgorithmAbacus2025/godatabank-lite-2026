# UK Welfare Fraud and Error Trends, 2026

This workbench records the evidence used for the ALIS-Light public report on
welfare fraud and error trends.

## Evidence source

Office for Budget Responsibility, **Welfare trends report**, June 2026,
CP 1634.

Local PDF:

`source_documents/E03599306_OBR_WTR_2026_Accessible_v3.pdf`

The milestone request referred to the descriptive filename
`obr_welfare_trends_report_june_2026.pdf`; the uploaded file uses the OBR
document filename shown above. The file was not renamed or duplicated.

## Evidence files

- `source_records/source.json` records PDF identity, metadata, and hash.
- `analysis/analysis.json` records each published claim with PDF and printed page
  provenance.
- `verification.md` records text extraction and rendered-page checks.

No internet source, backend pipeline, validator, publisher change, or new
architecture is used by this workbench.
