# England and Wales Fertility by Birth Cohort: 2024

This workbench records the evidence used for the ALIS-Light public report on
the ONS release **Fertility for those born in different years, England and
Wales: 2024**.

## Evidence rule

The GovDelivery newsletter is a discovery lead only. It is not used as evidence
for any figure or interpretation.

The evidence sources are the official ONS statistical bulletin, official ONS
XLSX dataset, and official ONS quality and methods guide recorded in
`source_records/source.json`.

## Files

- `fetched/ons_fertility_birth_cohort_2024.xlsx` — downloaded official ONS
  dataset.
- `source_records/source.json` — source URLs, release details, retrieval time,
  and file hash.
- `analysis/analysis.json` — selected figures with worksheet and cell
  provenance.
- `verification.md` — independent cross-checks and publication limits.

No backend pipeline or new architecture is used by this workbench.
